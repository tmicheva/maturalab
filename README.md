# МатураЛаб — офлайн версия

Една папка дава две инсталации:

- **PWA** — приложение, което се инсталира от браузъра на телефона и работи без интернет.
- **Android APK** — файл за инсталиране на телефони с Android.

И двете се създават автоматично от GitHub при всяко качване на промени.

## Какво работи офлайн

На компютър: отвори `www/index.html` с двоен клик – работи директно, без инсталация.

| Работи | Не работи офлайн |
|---|---|
| БЕЛ тест, отворени задачи, текстове към задачите | AI обратна връзка (есе и отворени задачи) |
| Счетоводни казуси, таблици, калкулатор | Разпознаване на тест от PDF |
| Есе: структура, показатели, образци | Обща синхронизация на материалите между устройствата |
| PDF за Classroom, прогрес | |
| Зареждане на материали от Excel | |

Резултатите и материалите, заредени от Excel, се пазят само на устройството.

## 1. Качване в GitHub (еднократно)

1. Създай ново хранилище в GitHub, например `maturalab`. Може да е частно, но за безплатен GitHub Pages трябва да е публично.
2. Качи **цялото съдържание** на тази папка, включително скритата папка `.github`. В браузъра ползвай *Add file → Upload files*.
3. Отвори *Settings → Pages → Build and deployment → Source* и избери **GitHub Actions**.

След всяко качване в клон `main` се стартират два процеса в раздел **Actions**:

- **PWA (GitHub Pages)** — публикува приложението на `https://<потребител>.github.io/maturalab/`.
- **Android APK** — компилира APK файла. Отнема около 5–8 минути.

## 2. Инсталиране като PWA

1. Отвори адреса от GitHub Pages на телефона в Chrome (Android) или Safari (iPhone).
2. Изчакай страницата да се зареди напълно. При това се запазва за работа без интернет.
3. Инсталирай приложението:
   - **Android:** меню ⋮ → **Инсталиране на приложението** (или *Добавяне към началния екран*);
   - **iPhone:** Сподели → **Добави към началния екран**.

След това приложението се отваря от иконата и работи без интернет. Когато има интернет, то проверява за нова версия само.

PWA може да се качи и на училищен сървър (IIS, nginx, Apache). Достатъчно е съдържанието на папка `www`, но сървърът задължително трябва да е с **HTTPS**, иначе работата без интернет не се включва.

## 3. Инсталиране на APK

1. В GitHub отвори **Actions → Android APK → последното успешно изпълнение**.
2. Изтегли **MaturaLab-apk** от *Artifacts*. Това е zip архив, вътре е `app-debug.apk`.
3. Изпрати APK файла на учениците, например в Classroom или Google Drive.
4. На телефона: отвори файла → разреши *Инсталиране от неизвестни източници* → **Инсталиране**.

В APK бутонът „Запази като PDF“ отваря менюто за споделяне. Оттам ученикът може да избере директно Google Classroom.

> APK файлът е подписан с тестов ключ (debug). Подходящ е за инсталиране в класа. За Google Play е нужен собствен ключ за подпис.

## 4. Нови материали

**Вариант А — вграждане в нова версия (за всички):**

1. В онлайн версията (claude.ai) отвори **Материали → За офлайн версията → Изтегли content.json**.
2. Замени `www/content.json` в хранилището с новия файл.
   (Файлът `www/content.js` е копие на материалите. Използва се само когато `index.html` се отвори с двоен клик. В GitHub е достатъчно да смениш `content.json`.)
3. GitHub създава нова версия:
   - PWA се обновява сама при следващото отваряне с интернет;
   - APK трябва да се инсталира наново.

**Вариант Б — Excel файл (без нова версия):**

1. Учителят изтегля шаблона от **Материали → Изтегли шаблона** и го попълва.
2. Изпраща Excel файла на учениците.
3. Всеки ученик отваря **Материали → Зареди файл**.

Материалите остават на неговото устройство, докато не натисне *Върни вградените материали*.

## Локално компилиране (по желание)

Нужни са Node.js 20, JDK 17 и Android Studio.

```bash
npm install
npx cap add android
rm -rf android/app/src/main/res/mipmap-anydpi-v26
cp -r android-res/* android/app/src/main/res/
npx cap sync android
npx cap open android      # Build → Build APK(s)
```

## Съдържание

```
www/                  приложението (PWA): index.html, content.json, sw.js, manifest, шрифтове, библиотеки
android-res/          икони за Android
capacitor.config.json настройки на Android приложението (bg.maturalab.app)
package.json          Capacitor 6
.github/workflows/    автоматично публикуване (Pages) и компилиране (APK)
icon.png              иконата в 1024×1024
```
